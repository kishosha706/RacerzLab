# Source Guides

Raw guide files in this folder are local development/reference inputs.
Runtime RacerZLab knowledge uses reviewed JSON records under
`racelab_engine/knowledge/setup/data`.

Do not blindly copy source tables into UI output. The master setup matrix is
RacerZLab-owned consolidated knowledge. PDFs and images may stay local if
desired. Commit reviewed derived knowledge, not raw copyrighted or unreviewed
files unless that is intentional.

Future ingestion can read markdown, JSON, or text extracts from this folder.
