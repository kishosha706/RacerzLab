# Chris Haye Setup Cheat Sheet Review

Source reference: user-provided setup cheat sheet image.

Review status: accepted as general setup guidance with car-capability gating.

## Accepted Concepts

- Brake bias should be read from lock order and brake-entry stability. Repeated front lock points toward less front bias; rear instability under braking points toward more front bias. Overall brake pressure is a separate car-supported adjustment and should be used cautiously.
- Slow damper changes apply to braking, acceleration, and turning weight transfer. Fast damper changes apply to bumps, curbs, and sharp platform events. Higher damper values can make the car more responsive; lower values can make it more stable or compliant, depending on the package.
- Ride height should be interpreted with platform, scrape, and speed evidence. Low platform targets are useful only if the car is not grounding, choking, or losing speed.
- Tire temperature patterns can point toward pressure, toe, or camber context, but cold or short samples should not be treated as proof.
- Low top speed can come from aero drag, gearing, toe scrub, or poor exit speed. Normalize exit speed and throttle before ranking gearing or drag-related setup changes.

## Gated Concepts

- Front wing angle, rear wing angle, and wing-value advice are road/aero-car setup concepts. They must not surface as NASCAR Next Gen oval recommendations unless the selected car exposes those adjustments.
- Diff coast and diff power locking language is differential-system context. Use only the selected car's supported diff levers, and validate with throttle, yaw, RPM, and phase evidence.
- Overall brake pressure is not the same as brake bias and is not a generic Next Gen oval recommendation.

## Do Not Overclaim

- Do not translate road-car wing changes into unsupported oval setup logic.
- Do not claim measured downforce from ride-height, rake, or diffuser proxy context.
- Do not recommend multiple major setup changes from the cheat sheet as one test.
- Do not treat driver-feel notes as proof without comparable-zone validation.
